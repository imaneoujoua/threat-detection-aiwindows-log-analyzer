⚔️ Types d'attaques détectées par le système
💣
DoS / DDoS
Envoi massif de connexions pour saturer le serveur. Caractérisé par : nb_connections > 700, error_rate > 0.7, durée < 0.1s.
CRITIQUE
🕵️
Intrusion
Accès non autorisé via ports sensibles (SSH:22, RDP:3389, SQL:1433). Durée longue, peu de connexions simultanées.
ÉLEVÉ
🦠
Malware C&C
Communication avec serveur de commande. Trafic symétrique (bytes_ratio ≈ 1), ports suspects (4444, 6667), connexions périodiques.
ÉLEVÉ
🎣
Phishing
Faux serveur web. Beaucoup de données échangées sur port 80/443, bytes_sent > 1500, durée courte.
MOYEN
🔐
Brute-Force
Tentatives répétées sur SSH/RDP. 732 échecs détectés dans les logs. Cibles : comptes admin et root.
CRITIQUE
👻
Zero-Day (IF)
Attaques inconnues détectées par Isolation Forest. Aucun exemple d'entraînement nécessaire — analyse comportementale pure.
